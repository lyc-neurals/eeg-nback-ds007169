# Illustrative sub-001 outputs

`sub001_behaviour.png` and `sub001_roi_bandpower.png` are small PNGs preserved
from the **executed notebook supplied with this repository project**. They
are snapshots of a single participant's descriptive analysis, not outputs
recomputed from included raw data. Download OpenNeuro ds007169 and run the
pipeline to regenerate the full set of tables and figures. The ROI figure
must not be interpreted as a causal workload effect because difficulty and
block order are confounded.
